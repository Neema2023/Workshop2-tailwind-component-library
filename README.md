# Tailwind Component Library

## Week 3 – Workshop 2

A reusable UI component library built with Tailwind CSS and Vite.

## Components

- **Buttons:** Primary, Secondary, Outline, and Disabled.
- **Cards:** Profile Card and Product Card.
- **Alerts:** Success, Warning, Error, and Information.
- **Responsive layout:** Adapts to different screen sizes.
- **Reusable styles:** Shared button, card, and alert classes.

## Technologies

- HTML
- JavaScript
- Tailwind CSS v4
- Vite

## Design Trade-off

We chose reusable component classes to reduce repeated styling and make the design easier to maintain. This improves consistency, although creating reusable classes requires an initial setup step.
